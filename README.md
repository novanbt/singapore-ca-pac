# Singapore Ca Pac — Smart Accounting & Financial Advisory

Professional accounting, corporate tax advisory, bookkeeping, and fractional CFO platform for **Ca Pac SG** in Singapore. Includes an interactive public web platform and real-time Admin Control Panel for consultation management and live site customization.

---

## 🌟 Features

### 🌐 Public Website
- **Modern Brand Design:** Crafted with high aesthetic fidelity in a dark-teal (`#002B29`) and mint-accent (`#16D5C5`) design system.
- **Hero & Story Showcase:** Hero quote card, high-resolution imagery, and interactive company story modal.
- **Capability Progress Bars:** Animated intersection-observer progress metrics for core services.
- **Interactive Service Detail Modals:** Scope of deliverables and timelines for Bookkeeping, Corporate Tax, CFO Advisory, and Secretarial services.
- **Location & Google Maps Integration:** Embedded interactive map and direct Google Maps directions to the Singapore office (`50 Chin Swee Rd, #06-04, Singapore 169874`).
- **Live Consultation Booking:** Responsive booking form with validation, immediate feedback, and real-time backend synchronization.

### 🛡️ Admin Management Panel (`/admin.html`)
- **Bookings & Inquiries Management:** Review incoming client consultation appointments, update status (`Pending`, `Confirmed`, `Completed`, `Cancelled`), add manual entries, and export records to CSV.
- **Website Content & Settings Editor:** Update phone number, email, address, operating hours, hero headlines, and capability metrics live without touching code.
- **Admin Account Security:** In-app credential manager to change admin username/email and password with password verification.

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)

### Run Locally
```bash
# Start the local server
npm start
# or
node server.js
```

- Public Website: [http://localhost:3000](http://localhost:3000)
- Admin Panel: [http://localhost:3000/admin.html](http://localhost:3000/admin.html)
